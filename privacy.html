隱私權政策

適用於「Yu Nexus 備份」（Yu Nexus 的 Google 雲端硬碟備份功能）　生效日期：2026 年 11 月 6 日

1. 會存取哪些 Google 資料

  • Google 授權憑證：你同意授權後，Google 發給程式的存取憑證，用來代表你上傳備份。
  • 你挑選的備份資料夾：你在 Google 選擇畫面中指定的雲端硬碟資料夾。
  • 程式自己上傳的備份檔：包含檔名、大小、日期與檢查碼，用來確認上傳完整並淘汰舊檔。

程式只使用 https://www.googleapis.com/auth/drive.file 權限，無法存取你雲端硬碟中其他任何檔案，也不讀取你的 Gmail、聯絡人、相簿或個人資料。

2. 資料用途

上述資料只用來：上傳加密備份包、核對上傳內容、只保留最近兩個成功日期並移除較舊的備份包。除此之外不作任何用途。

  • 不用於廣告、行銷或分析。
  • 不出售、不出租，也不提供給任何第三方。
  • 不用於訓練人工智慧或機器學習模型。
  • 除了你本人，沒有人會讀取你的資料；開發者也不會。

3. 資料存放位置

  • 授權憑證只存在你自己的電腦上，並以 Windows 資料保護（DPAPI）加密，只有同一個 Windows 使用者能解開。
  • 備份內容在上傳前就已在你的電腦上加密。
  • 開發者沒有架設任何伺服器；資料只在你的電腦與 Google 之間直接傳送。

4. 保留與刪除

  • 雲端只保留最近兩個成功日期的備份包。
  • 你可以隨時在 Google 雲端硬碟刪除備份資料夾。
  • 你可以隨時到 Google 帳戶的「第三方應用程式與服務」 移除「Yu Nexus 備份」的存取權，移除後程式就無法再上傳。

5. Google API 服務使用者資料政策

Yu Nexus 備份對 Google API 所取得資料的使用與傳輸，遵守 Google API 服務使用者資料政策，包括其中的「有限使用（Limited Use）」規定。

6. 本頁網站

本說明頁由 GitHub Pages 代管，本身不使用 Cookie 或分析工具；GitHub 可能依其政策記錄一般連線資訊。

7. 政策變更與聯絡方式

本政策如有變更，會更新本頁與生效日期。有任何問題請來信：pig910999@gmail.com

English summary

Yu Nexus Backup uses only the drive.file scope. It accesses only the Google authorization tokens you grant, the Drive folder you pick, and the encrypted backup files it uploads (name, size, date and checksum), solely to upload, verify and rotate backups (keeping the latest two successful dates). Data is not used for advertising or analytics, not sold or shared with third parties, not used to train AI/ML models, and not read by anyone but you. Tokens are stored only on your computer, encrypted with Windows DPAPI; backups are encrypted before upload; there is no developer server. You can delete the backup folder at any time and revoke access at myaccount.google.com/permissions. Use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Contact: pig910999@gmail.com.
