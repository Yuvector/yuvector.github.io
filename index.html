Yu Nexus 備份

Windows 桌面工具 Yu Nexus 的 Google 雲端硬碟加密備份功能

Yu Nexus 是一套在 Windows 電腦上執行的個人工作工具，用來整理庫存與合約交貨資料。「Yu Nexus 備份」是它的雲端備份功能：程式每天先在電腦上做好一份加密的完整備份包，再透過 Google Drive API 上傳到使用者自己選擇的 Google 雲端硬碟資料夾，作為電腦故障時的還原來源。

它怎麼運作

  • 使用者在程式的「設定」中按下登入，透過 Google 的畫面同意授權，並挑選要放備份的資料夾。
  • 程式在本機完成加密備份包後，自動上傳到該資料夾，並核對大小與內容。
  • 雲端只保留最近兩個成功日期的備份包，較舊的會由程式移除。
  • 上傳失敗時，本機與雲端原有的備份都會保留。

使用的 Google 權限

只使用一個權限：https://www.googleapis.com/auth/drive.file

這個權限只能存取「這個程式自己建立的檔案」與「使用者在 Google 選擇畫面中挑選的資料夾」。程式看不到也讀不到你雲端硬碟裡的其他檔案。

誰會使用

這個工具不公開發行，只供開發者本人與其授權的少數同事使用。每位使用者都登入自己的 Google 帳號。

隱私權

程式不經過開發者的伺服器，也不蒐集、出售或分享任何資料。詳細內容請看 隱私權政策。

English summary

Yu Nexus Backup is the cloud backup feature of Yu Nexus, a private Windows desktop tool for managing inventory and contract delivery records. It creates an encrypted backup package on the user's own computer and uploads it, through the Google Drive API, to a Google Drive folder that the user chooses. It requests only the drive.file scope, so it can access only files it created or the folder the user selected. The tool is not publicly distributed and is used only by its developer and a few authorized colleagues. See the Privacy Policy.
